## サービス別カラム差分

**差分なし。** 全27種類のCSVで完全に同一のカラム構造。

介護サービス系（jigyosho_XXX.csv）ではサービス種別ごとにカラム数が異なることがあったが、
障害福祉サービス系は完全統一されている。これは実装上の大きな利点。

## 構造上の注意点

### 1. 事業所番号（列14）の重複
- 同一事業所番号で複数レコードが存在するケースがある
- 放デイ: 175件の事業所番号に2レコードずつ（合計350レコード）
- 原因: 同一法人が同じ事業所番号で複数拠点を運営（事業所名末尾に「5」「6」等の枝番）
- **対策: `office_code + service_type` を複合キーとし、重複は事業所名で区別**

### 2. 放デイ/児発の多機能型事業所
- 放課後等デイサービスと児童発達支援で**12,793件の事業所番号が重複**
- これは同一事業所が両サービスを提供している「多機能型事業所」
- 放デイ固有: 11,175件 / 児発固有: 3,339件 / 共通: 12,793件
- **実質ユニーク事業所: 27,307件**（40,403件ではない）

### 3. 都道府県コード（列0）
- 5桁の市区町村コード（例: `01100` = 札幌市中央区）
- 先頭2桁が都道府県コード
- pref_code の抽出: `code[:2]`
- city の特定: 列15（事業所住所の市区町村部分）を使用

### 4. 法人番号（列5）
- 充填率: 放デイ90.0%、児発90.2%
- 13桁の法人番号。国税庁データとの紐づけに使える
- 約10%が空欄（個人事業主や任意団体）

### 5. 緯度経度（列20, 21）
- **全レコード100%充填（全27種別）**
- 形式: 小数点以下8桁の浮度（例: `43.03650060`, `141.34672820`）
- 日本国内の範囲チェック済み: 異常値なし
- ジオコーディング完全不要

### 6. 営業時間（列22-27）
- 平日: 82.0%（放デイ）/ 81.3%（児発）
- 土曜: 62.3% / 54.2%
- 日曜: **11.7% / 12.2%** — ほとんどの事業所が日曜休み（空欄=日曜非営業の意味）
- 祝日: 43.4% / 35.5%
- 定休日: 80.1% / 79.7%
- **日曜・祝日の低充填率は欠損ではなく「その曜日は営業していない」の意味**

### 7. 定員（列28）
- 充填率: 放デイ82.9%、児発82.1%
- 定員ゼロ: 8件（放デイ）/ 10件（児発）→ 実質未設定扱い
- 相談支援系やヘルパー派遣系は定員概念がないため0%（正常）

### 8. 事業所URL（列19）
- 充填率: 放デイ67.4%、児発69.0%
- 約30%はURL未登録 → MVPでは「URL未登録」表示で対応
- 法人URL（列10）の方が充填率が高い場合がある → フォールバック候補

### 9. 文字化け・異常値
- 目視確認で文字化けなし（UTF-8 BOM付きで安定）
- 電話番号はハイフン付き（例: `045-912-0733`）で安定
- URLは `http://` `https://` 混在あり → 正規化で対応
