## MVP向けに十分な品質か

**十分。** 以下の根拠:

1. **必須項目（名前・住所・電話・緯度経度・サービス種別）が99.9%以上充填**
2. **47都道府県すべてにデータあり** — 全国展開に障害なし
3. **カラム構造が全種別統一** — パーサー実装が単純
4. **事業所番号の重複は極めて少ない**（放デイ0.7%、児発0.7%）— 主キーとして使える
5. **ジオコーディング完全不要** — コストゼロで地図表示可能

---

## 最初に扱うべきサービス

**放課後等デイサービス + 児童発達支援（同時リリース）**

理由:
1. 検索需要が最大（保護者が自ら検索する）
2. 多機能型事業所が12,793件あり、両方を同時に出すのが自然
3. 実質27,307件のユニーク事業所で、訪問診療ナビ（15,759件）より大きいが管理可能
4. データ品質が全サービス中で最高レベル

## `convert_shogai_data.py` に入れるべき最重要ルール

1. **UTF-8 BOM対応**: `encoding="utf-8-sig"` で読み込み
2. **pref_code抽出**: 列0（市区町村コード）の先頭2桁
3. **住所結合**: `f"{row[15]}{row[16]}"` で全住所を生成
4. **全角→半角**: サービス種別の`Ａ`→`A`、`Ｂ`→`B`
5. **多機能型検出**: 放デイCSVと児発CSVの事業所番号をクロスチェック
6. **重複行レポート**: 同一事業所番号の重複を検出してログ出力（削除はしない）
7. **build_site互換形式**: `kikan_cd` = `{office_code}-{service_slug}`
8. **品質ゲート**: 全国47都道府県チェック、必須項目充填率チェック
