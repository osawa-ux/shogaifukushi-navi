# MVP フィールド判定ポリシー

分析日: 2026-04-12
対象: 放課後等デイサービス (24,156件) + 児童発達支援 (16,247件)

---

## 判定基準

| 基準 | 内容 |
|------|------|
| 充填率 | 80%以上 → 表示可能 / 50-80% → 条件付き / 50%未満 → 非表示推奨 |
| ユーザー重要性 | ユーザーが事業所を探す際に必要な情報か |
| UIでの見せやすさ | 一覧・詳細ページで自然に表示できるか |
| サービス間一貫性 | 放デイ・児発で同等の品質か |
| 誤解リスク | 欠損が多い場合に「情報がない」と誤解されないか |

---

## 放デイ＋児発 MVPの推奨表示レイアウト

### 一覧ページ（市区町村別）に表示する項目

```
[事業所名]               [サービス種別バッジ: 放デイ / 児発]
[住所（市区町村＋番地）]
TEL: [電話番号]           定員: [定員]名
[平日営業時間]            [定休日]
```

### 詳細ページに表示する項目

```
# [事業所名]

## 基本情報
| 項目 | 内容 |
| サービス種別 | 放課後等デイサービス |
| 住所 | [都道府県][市区町村][番地] |
| 電話番号 | [TEL] |
| FAX | [FAX]（あれば） |
| 公式サイト | [URL]（あれば） |
| 定員 | [定員]名 |
| 運営法人 | [法人名] |

## 営業時間
| 曜日 | 時間 |
| 平日 | [hours_weekday] |
| 土曜 | [hours_saturday]（あれば） |
| 定休日 | [closed_days] |

## アクセス
[地図（lat/lng）]

## 近隣の事業所
[同市区町村の他事業所リスト]
```

## 欠損時の表示ルール

| フィールド | 欠損時の表示 |
|-----------|------------|
| URL | 非表示（「公式サイト」行ごと削除） |
| FAX | 非表示 |
| 定員 | 「- 名」または非表示 |
| 営業時間 | 「お問い合わせください」 |
| 定休日 | 「お問い合わせください」 |
| 法人名 | 表示必須（100%充填なのでケースなし） |
